- **Python 3.12 or newer is now required for the command-line package** (`rxd`): it uses the radar-reading library xradar 0.13, which needs Python 3.12. The installers are not affected (they carry their own Python). The new library reads some files more completely and more correctly, so exported files can differ from earlier ones in the data, not in layout or units: a NEXRAD sweep that lost radials is whole (720 instead of 718 rays in our example), ODIM total power is `DBTH` in dBZ instead of an unlabelled `TH`, IRIS gates without data are empty instead of values such as -32 dBZ, HPL lidar sweeps keep their last ray, and a CfRadial1 export keeps rays that share a time stamp. {doc}`OUTPUT_STANDARDS` lists them.
