- **The engine starts about 30 % faster** (the analysis engine is ready after about 0.5 s instead of 0.7 s), because file-format and image libraries are now loaded in the background after start-up instead of before it. New opt-in setting `XRADAR_FLOAT32=1` keeps decoded Level II style moments as 32-bit numbers: half the memory for them, values within 6e-8 of their size (written files say so in `numeric_precision`). Slowdowns of several times are now caught by an optional benchmark check that maintainers can run on a pull request.
