- **ERA5 reanalysis data**: hourly global fields and profiles from the public ERA5 copy on Google Cloud, for any date since 1940 and any place. Only the levels and latitudes you ask for are downloaded (a seven-level profile is about 17 MB instead of 526 MB), the exact size is shown and approved first, the nearest hour is used and named (never interpolated), and everything is labelled as a model. Available as `rxd env ... era5` ({doc}`source-era5`). ERA5-Land is not offered.
