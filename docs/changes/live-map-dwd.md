- **European radars on the live map:** the live map now works with two networks, NEXRAD (USA) and DWD (the 17 German radars, from the German Weather Service's Open Data, CC BY 4.0). Choose either in *Radars...* (a map switch between the two, and a search that also lists radars of other networks with the reason they are not live), and mix them if you like. The dialogs name the right server (`opendata.dwd.de` for DWD) and the exact sizes (a DWD volume is about 1.5 to 2.5 MB, but each update reads two folder indexes of about 2.1 MB per DWD radar), and the credit and licence travel into the label on the map, the Layers panel and the saved NetCDF and PNG. **Set as default radar** on the radar network map now works for DWD radars, and for the others says why it cannot. Each radar's ring is its own range. Opened DWD volumes are held in memory and use no extra disk. {doc}`LIVE` says exactly which networks are live and why the others (EUMETNET OPERA, FMI, KNMI, DMI, SMHI, Météo-France, South Africa) are not yet.
- **The live map of far-away radars is the right way up:** the map is centred on the radars it shows, not on a default over the USA, so a view of Germany (or Alaska, Hawaii) no longer comes out turned sideways with its place names reading vertically.
- **The US airport radars (TDWR) work on the live map too:** their volumes are in the same public bucket as NEXRAD's, so the 47 TDWR radars can be found by search in *Radars...* and set as default radars from the radar network map.
