- **Signing in without typing a password in a terminal.** `rxd login --password-stdin` (one line from standard input, like `docker login`), `rxd login --browser --provider google|apple|facebook` for accounts that have no password (PKCE with a one-shot loopback listener; it needs a browser on the same computer), and clearer messages about which program renews a sign-in (`rxd whoami`; an expired app sign-in says exactly what to do). Renewing the session is now safe under parallelism: many jobs on one shared home folder renew it **once** (a lock that also works on network file systems, because the server's refresh-token rotation ends the whole session when a token is used twice), and a short outage no longer makes every job wait. See {doc}`ACCOUNTS` and {doc}`CLI`.
- **Access tokens for batch jobs, cron, CI and clusters.** Create a token in *Account > Access tokens* (a name, an expiry of 7 days to 1 year, at most 10 active; shown once; only its fingerprint is stored; revoke any time), then `rxd login --token < token.txt` or set `RADARX_TOKEN` (nothing written to disk) so `rxd` and `import rxd` sign in without a password or a browser. The token is exchanged for a one-hour entitlement token by a new Edge Function, checked offline by the program, and the token's own expiry date holds even offline. A revoked token keeps working for up to an hour (and up to the 30-day offline allowance when the server cannot be reached): {doc}`ACCOUNTS` lists every limit and the owner's set-up steps (a key script, two function deployments, one migration). Not verified on a real deployment.
