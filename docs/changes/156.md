- **Signing in without typing a password in a terminal.** `rxd login --password-stdin` (one line from standard input, like `docker login`), `rxd login --browser --provider google|apple|facebook` for accounts that have no password (PKCE with a one-shot loopback listener; it needs a browser on the same computer), and clearer messages about which program renews a sign-in (`rxd whoami`; an expired app sign-in says exactly what to do). Renewing the session is now safe under parallelism: many jobs on one shared home folder renew it **once** (a lock that also works on network file systems, because the server's refresh-token rotation ends the whole session when a token is used twice), and a short outage no longer makes every job wait.
