- **Accessibility.** An automated audit of the main screens in the light and dark themes (axe-core in headless Chrome) found headings, landmarks and one scroll area that keyboard and screen-reader users could not use properly; they are fixed, and three dialogs (colormap editor, data table, metadata viewer) now keep keyboard focus inside while open and give it back when closed. A first step towards translations is in place (a message catalogue helper and one translated-ready dialog); no language was added yet.
