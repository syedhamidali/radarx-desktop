- **Sign-in tokens leave the plain-text file**: the app and `rxd` keep your access and refresh tokens in the system credential store (Credential Manager on Windows, Keychain on macOS, Secret Service on Linux) instead of a readable `session.json`. An existing sign-in moves there on its own and you stay signed in. Without a credential store (no desktop session, a cluster login node) the tokens stay in a file that only your user can read, and on Windows its access list now names only you. {doc}`ACCOUNTS` explains what this does and does not protect, and `RADARX_CREDENTIAL_STORE` chooses.
