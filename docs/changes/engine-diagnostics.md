- **The engine says plainly when its port is taken, and keeps its crash report**: starting the engine on a port that is already in use now prints one line ("port N is already in use ... use another port with --port") and ends with its own exit code (75), instead of a long error trace. The engine's crash log (in `.xradar-desktop` in your home folder, `%USERPROFILE%\.xradar-desktop` on Windows) is renamed to `engine-crash.log.1` when it grows over 512 KB, instead of being deleted, so the latest crash report survives; at most two files exist.
