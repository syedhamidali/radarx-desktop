- **A stuck or runaway analysis is easier to get out of.** Cancelling a module now really stops it (and an export, batch or animation stops at its next step and leaves no half-written file); a module that grows past 75 % of the computer's memory is stopped with a message (`XRADAR_MODULE_MAX_MB`); cloud listings and downloads give up after five minutes with a clear message (`XRADAR_CLOUD_TIMEOUT_S`); and an engine whose event loop is stuck for a minute restarts itself, while the app warns after 30 s of silence. {doc}`STABILITY` has the details and what is still open.
