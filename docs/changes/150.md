- **An account is now required everywhere.** radarx-desktop needs a free account in the app, in the engine, in `rxd` (new `rxd login`, `rxd logout`, `rxd whoami`; exit code 5 without a sign-in; the deprecated `xrd` too) and in Python (`rxd.AccountRequired`). One session file is shared by all of them, a sign-in works offline for 30 days after the server last checked it, and `entitlement_allows()` is the one place a future subscription check will go (no billing yet). The public web engine has the same gate (`RADARX_WEB_REQUIRE_ACCOUNT`, on by default). Each account sends a small **feature-level activity log** (never file names, places or data), listed under *Account > Activity*; the privacy notice and terms version are updated, so everyone is asked to accept again. A client-side check can be removed from source-available code: {doc}`ACCOUNTS` says what the gate does and does not do.
