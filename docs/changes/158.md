- **Report an issue.** *Report an issue* in the About dialog, the command palette and the Account dialog sends a bug, an idea or a question to the project (10 a day per account). Optional diagnostics (off by default: engine messages from this session, scrubbed of paths, file names, e-mail addresses, keys and IP addresses) are shown in full before sending, and a failed send keeps your text. Behind it: a `report-issue` Edge Function that the website form shares (Turnstile for visitors, your sign-in for the app, rate limits, an owner notification by Resend then Mailjet, an optional private GitHub copy) and an `issue_reports` table that only the owner can read (kept 24 months). The mail code now lives in `supabase/functions/_shared/`, so redeploy `send-auth-email` too. See {doc}`REPORTING` and {doc}`PRIVACY`.
