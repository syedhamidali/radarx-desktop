- **MRMS radar products**: the NOAA 1 km, 2-minute mosaics (3-D and composite reflectivity, rain rate, radar-only and gauge-adjusted accumulations, precipitation type, hail size, rotation tracks, echo tops) for a time you choose. The exact size is shown and approved first, the nearest file is used and named (never interpolated), and each layer says whether it is radar only, model-assisted, gauge-adjusted or a model field. Available as `rxd env ... mrms` ({doc}`source-mrms`); reading the files needs the optional ecCodes package.
