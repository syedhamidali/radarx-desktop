- **Event report.** `rxd report` writes one self-contained HTML document of a rainfall event: summary numbers with units and class, accumulation map, basin table, map and series, gauge validation, methods with references, the run record and the credits; every figure and number is labelled as an estimate with its uncertainty where known. `--record` saves the run record and `--from-record` makes the same report again from it. See {doc}`HYDROLOGY`.
