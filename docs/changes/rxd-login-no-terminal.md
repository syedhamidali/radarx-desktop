- **`rxd login` explains itself when it cannot ask for a password**: with no terminal (input redirected, an editor or agent shell, a scheduled job) it now says there is no terminal to type into, what to do (a normal terminal window, `ssh -t`, or the app) and stops with exit code 5, instead of waiting for ever on Windows or reporting an internal bug. Ctrl-D at a prompt cancels cleanly. There is still no way to give the password to a script, by design. {doc}`CLI` has the details.
