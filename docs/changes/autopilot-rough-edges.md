The Autopilot opens when a single folder is dropped (and follows folders that are symbolic links), shows where its memory budget comes from (`RAM 17.2 GB, available 3.0 GB -> budget 2.7 GB`: the smaller of 60 % of RAM and 90 % of the memory free now), keeps the results written before a Cancel and says what was cancelled (*Run again* resumes), and no longer opens a mosaic or other map grid as an empty radar view: those offer *show in folder*, and opening one as a radar file explains that it is a gridded product. Mosaics and winds of a series are named after the time of the radar the steps follow, so one no longer overwrites another, and creating a NetCDF file no longer prints a harmless HDF5 error stack in the engine log.
