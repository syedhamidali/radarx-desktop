- **Radar network map**: the Cloud data panel's new *Map* tab (also *Radar network map* in the command palette) shows every weather radar in a bundled catalogue of 1005 sites (NOAA NCEI HOMR for NEXRAD, the EUMETNET OPERA database for Europe, WMO OSCAR/Surface worldwide), each with the source and licence of its position and a marker shape that says what the app can do with its data: loadable, open data (link), key required, restricted or unknown. Search by id, name, country or network; filter by access class, network and country; click a site for its card with *Open latest scan*, *Choose a time (archive)*, *Open the provider's page* and a *Set as default radar* hook. Markers are drawn on a canvas and grouped when zoomed out, so the whole catalogue stays fast.
- **Two more open networks load directly**, with consent dialogs that name the server and the exact size: **DWD Open Data** (the last two days of the 17 German radars: ten sweeps every five minutes, reflectivity and radial velocity, assembled from DWD's per-sweep ODIM files into one volume; CC BY 4.0 with the source acknowledged) and the **FMI open-data sample on AWS** (full polar volumes of ten Finnish radars for 7 and 8 February 2023; CC BY 4.0). The credit line and licence of the network travel with the layer into every export. Data opened from NEXRAD on AWS now carry their NOAA credit the same way.
