- **A mistyped request to the engine is no longer reported as "not signed in"**: a request the engine does not know is now answered "Unknown message type" whether or not anyone is signed in, and a request whose type is not text gets a plain error instead of breaking the connection's handler. Known requests are still refused until a sign-in is present. {doc}`ACCOUNTS` also says plainly what works offline (the 30-day rule is unchanged).
