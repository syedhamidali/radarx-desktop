- **HRRR model data and `rxd env`**: the 3 km HRRR model (CAPE, helicity, shear, reflectivity, temperature, wind and hydrometeor fields, and a model column read as a sounding) can be fetched for a time you choose. Only the fields you pick are downloaded, the exact size is shown and approved first, the nearest hourly time is used and named (never interpolated), and everything is labelled as a model. `rxd env` does the same from the terminal ({doc}`environment-sources`). Reading the files needs the optional ecCodes package (`pip install "radarx-desktop-engine[grib]"`).
