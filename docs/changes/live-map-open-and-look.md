- **The live map's data are now yours to use:** *Open these volumes* (and *Open this volume* on each radar) opens the volumes behind the picture as normal files, so the 2D and 3D viewers, Mosaic, Multi-Doppler, cells, modules, cleaning and export all work on them, with no new download. They stay open when the live map updates, the app says how much disk they use, and closing a file gives the disk back (at most 8 at once). *View in 3D* and *Multi-Doppler winds from these radars* do the common cases in one click; if the radars do not overlap, the engine's own explanation is shown. *Save the composite* writes NetCDF or a georeferenced PNG with the NEXRAD credit and the analysis time. The Layers panel now says when the live composite is valid and which radars it was made of, instead of "Radar scan: unknown".
- **The live map looks better and says what it draws:** echo below 5 dBZ (the National Weather Service convention) is no longer painted, as a visible setting *Hide echo below N dBZ* whose number is also in the legend and the label (the data and exports are not changed); the grid is 1 km for up to four radars and is named in the label; the picture is smoothed instead of blocky; place names, roads and boundaries are drawn above the echo on a calmer basemap in both themes; range rings are thin and can be switched off; the view opens on the radars' footprint; and the left pane lists the radars and the volumes held instead of "No file loaded".
